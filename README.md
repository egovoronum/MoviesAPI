
# Movies API — Pytest Test Suite

This repository contains a lightweight automated test suite for a Movies API. Tests are written using pytest and rely on a custom ApiManager client for interacting with the backend.

## Features

### Movies

GET movie by ID (200 / 404)

GET movies list with validation

Filtering by price

Sorting by createdAt (ASC)

Create movie (201)

Delete movie (200)

Patch movie (200)

### Genres

GET genres list

GET random genre

Create genre

Delete genre

### Running

Running Tests

pytest
